**Дополнительные сведения:**

### Критерий

Нарушение = в `Api/` (или handler) есть `new T { … }` / `Method(new T …)` для:

- `*QueryOptions`, `*GetNewOptions`;
- CRUD Request/Response/Model (включая `*ListPageResponse`, `*DeleteResponse`, Delivered/Read);
- port/notify-модели сценария (`ChatNotify*Model`);
- domain events (уже через Mapper — ок).

Не нарушение: `new` внутри `Mapping/*Mapper.cs`; `new Dictionary` / `List` / массивы; `InvalidOperationException` в handlers.

### Инвентаризация

#### `*QueryOptions` / `*GetNewOptions` в Api

| Файл | Метод / место | Сейчас | Цель (Mapper) |
|------|---------------|--------|---------------|
| `ServiceRoom` | Create / Update (дубликат имени) | `new RoomQueryOptions { Name, ExcludeId? }` | `RoomMapper.ToQueryOptions(...)` |
| `ServiceRoom` | DisplayDeletePage | `new ChatQueryOptions { RoomId }` | `ChatMapper.ToQueryOptions(roomId:)` |
| `ServiceRoom` | DisplayListPage | `new RoomQueryOptions { Ids }` | `RoomMapper.ToQueryOptions(ids:)` |
| `ServiceChat` | DisplayListPage | `new ChatQueryOptions { RoomId }` | `ChatMapper.ToQueryOptions(roomId:)` |
| `ServiceParticipant` | Create / DisplayDelete / Delete / DisplayList | `new ParticipantQueryOptions { ChatId }` (×4) | `ParticipantMapper.ToQueryOptions(chatId:)` |
| `ServiceMessage` | DisplayCreate / Create | `new MessageGetNewOptions { … }` (×2) | `MessageMapper.ToGetNewOptions(...)` |

### Эталон после правки

```text
var queryOptions = RoomMapper.ToQueryOptions(name: nameNormalized);
var duplicates = await unitOfWork.Rooms.GetListAsync(queryOptions, cancellationToken);

var notify = ParticipantMapper.ToNotifyParticipant(...);
await chatNotifyPort.NotifyParticipantJoinedAsync(notify, cancellationToken);
```

Не: `GetListAsync(new RoomQueryOptions { … })`, не `Notify...(new ChatNotifyParticipantModel { … })`.
