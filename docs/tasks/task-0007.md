**Описание:**

Выбор чата в боковой панели открывает окно чата в центральной области: название чата сверху, место под сообщения и поле ввода внизу. Сообщения пока не хранятся и не отправляются — задача готовит экран, на который потом ляжет переписка.

**Функциональные требования:**

1. Открытие чата: щелчок по чату в боковой панели открывает его окно по адресу `/chat/{id}`; выбранный чат подсвечен в панели — адрес переживает перезагрузку и открывается по ссылке.
2. Окно чата: классический вид — название чата в верхней полосе с кнопкой закрытия перед ним, середина пустая (место под сообщения), поле ввода прижато к низу — разметка в [Окно чата](#окно-чата).
3. Поле ввода: многострочное поле «Напишите сообщение…», растёт по мере ввода; кнопка «Отправить» видна, но неактивна — отправка сообщений появится в следующих задачах.
4. Главная: когда чат не выбран, по центру — крупная надпись «Socium» и подсказка выбрать чат в панели.
5. Синхронизация с панелью: переименование открытого чата сразу меняет название в окне; удаление открытого чата или его комнаты возвращает на главную.
6. Неизвестный чат: по адресу несуществующего чата — сообщение «Чат не найден» и ссылка на главную; неизвестный адрес — переход на главную.

**Технические требования:**

1. Маршруты: `''` — главная, `chat/:id` — окно чата, `**` — переход на главную; параметр `id` передаётся во вход компонента (`withComponentInputBinding`).
2. Данные: название чата — существующий `GET /api/chat/info?id=…`; бекенд не меняется.
3. Название в верхней полосе: сервис `TopbarTitle` (`app/layout/topbar/`), окно чата задаёт название при загрузке и сбрасывает при уходе.
4. Синхронизация: сервис `ChatChanges` (`app/chats/`) — сигнал версии; боковая панель увеличивает версию после переименования и удаления чата и после удаления комнаты, окно чата при смене версии перезагружает данные.
5. Стили: только токены rule-0005; проверка в обеих темах.
6. Тесты: по [rule-0004](../rules/rule-0004-tests.md) — фронтенд-тесты новых компонентов и сервисов, E2E открытия чата.

**План реализации:**

1. Карточка и реестр.
2. Маршруты, главная `HomePage`, сервисы `TopbarTitle` и `ChatChanges`, `ChatApi.getInfo`.

4. Тесты фронтенда и E2E.
5. Сборка, прогон тестов, проверка в браузере в обеих темах, документы.

**Дополнительные сведения:**

### Окно чата

| Блок            | Поведение                                                                                     |
|-----------------|-----------------------------------------------------------------------------------------------|
| Верхняя полоса  | Слева — кнопка «×» («Закрыть чат», переход на главную) и название открытого чата, справа — переключатель темы |
| Середина        | Пустая область под будущие сообщения, прокручивается отдельно от поля ввода                   |
| Поле ввода      | Внизу по центру, ширина ограничена; `textarea` с подписью «Сообщение в чат X», растёт до нескольких строк; кнопка «Отправить» неактивна |
| Смена чата      | Набранный текст сбрасывается, данные загружаются заново                                       |
| Состояния       | «Загрузка…»; «Чат не найден» со ссылкой «На главную»; ошибка загрузки                          |
| Боковая панель  | Строка чата — ссылка на `/chat/{id}`; открытый чат подсвечен, у ссылки `aria-current="page"`  |
