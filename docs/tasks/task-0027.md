**Дополнительные сведения:**

### Заметка

As-is: пользователь вступает в чат сам (`ServiceParticipant.CreateAsync`), без одобрения. По 0021 вошедший пользователь без назначений не видит ни комнат, ни чатов, поэтому для запроса нужно решить, как он находит чат: ссылка, поиск или только приглашение. Запрос и приглашение — новые сущности со статусом (ожидает, принято, отклонено); хранение, уведомления и UI — при наполнении.
