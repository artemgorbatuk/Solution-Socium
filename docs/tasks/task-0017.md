**Описание:**

UX ленты: если пользователь ушёл вверх по истории, новые сообщения не уводят скролл вниз автоматически — показывается индикатор «↓ новые». Детали — при старте задачи.

**Функциональные требования:**

1. Индикатор: при новых сообщениях (realtime), если лента не у низа — кнопка / метка «↓ новые» — уточняется при старте.
2. Клик / действие: переход к хвосту ленты и сброс индикатора — уточняется при старте.

**Технические требования:**

1. Нет. — уточняется при старте (фронтенд поверх [task-0014](task-0014.md)).

**План реализации:**

1. Карточка и реестр.
2. Уточнить требования и наполнить карточку.
3. Реализация, тесты, документы.
4. Коммит.
