### Критерий

| Ситуация | Действие |
|----------|----------|
| Интерфейс и **одна** реализация в одной сборке, файлы разделены / файл `I*.cs` | слить в файл имени реализации |
| Интерфейс в Services.*, адаптер в WebApi / SignalR (искл. 2) | только rename `IFoo.cs` → `Foo.cs` |
| Marker-only, файл уже без `I` | leave as-is |
| Интерфейс + реализация уже в одном файле без `I` | leave as-is |
