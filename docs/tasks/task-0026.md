**Описание:**

Смена отображаемого имени пользователя (`PUT /api/account/profile`) сразу видна другим онлайн-клиентам: панель участников открытого чата, подписи отправителя в открытой ленте и превью «последнее сообщение» в сайдбаре — без перезагрузки страницы. Сейчас имя обновляется только у себя (локальный reload списка участников).

**Дополнительные сведения:**

### Заметка

As-is: `ServiceAccount.UpdateProfileAsync` пишет `User.Name` и не шлёт realtime; у инициатора `ParticipantsPanel` перечитывает список по смене `currentUser.name()`. У остальных участников чата и в уже загруженной ленте имя остаётся старым до GET/reconnect. Имя отправителя в сообщениях берётся из `User` при выдаче/notify сообщения, не хранится отдельно в тексте — после смены профиля достаточно патча UI по `userId` + новое `name`. Связка Security → notify (порт / domain event / Shared) и аудитория (всем на хабе vs только чаты, где пользователь участник) — при наполнении.
