### Заметка

As-is: CRUD чата обновляет UI только у инициатора (reload списка чатов комнаты); у остальных имя/наличие чата меняется после обновления страницы или повторной загрузки. Эталон по объёму и связке — [task-0020](task-0020.md): domain event после `SaveChanges` → handler → notify → SignalR (например `chatChanged`) → патч сайдбара. Аудитория и детали payload (roomId + chatId + name + kind) — при наполнении. Авточат [task-0019](task-0019.md) / будущий `ChatCreated` [task-0022](task-0022.md) согласовать при реализации, чтобы create в UI не дублировать.
