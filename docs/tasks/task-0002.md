**Описание:**

Добавить в репозиторий каркас фронтенд- и бекенд-проектов, чтобы оба приложения собирались, запускались локально и фронтенд мог обращаться к бекенду.

**Функциональные требования:**

1. Бекенд: проект запускается локально и отвечает на тестовый эндпоинт — проверка работоспособности API.
2. Фронтенд: проект запускается локально и открывается в браузере — стартовая страница приложения.
3. Связь фронтенда с бекендом: фронтенд вызывает тестовый эндпоинт бекенда и показывает результат — сквозная проверка, что приложения видят друг друга.

**Технические требования:**

1. Расположение: бекенд — в `src/backend/`, фронтенд — в `src/frontend/`.
2. Стек: фреймворки и версии выбирает разработчик — список решений в [Дополнительные сведения](#дополнительные-сведения).
3. Каркас без бизнес-логики: в проекты добавляется только необходимое для сборки, запуска и тестового вызова.
4. Конфигурация: адреса и порты задаются через конфигурацию, а не в коде; секреты в репозиторий не попадают.
5. Пустые папки: `.keepfolder` в `src/backend/` и `src/frontend/` удаляется после добавления проектов.

**План реализации:**

1. Зафиксировать выбранный стек в разделе [Дополнительные сведения](#дополнительные-сведения).
2. Создать бекенд-проект в `src/backend/` с тестовым эндпоинтом.
3. Создать фронтенд-проект в `src/frontend/` со стартовой страницей.
4. Настроить вызов бекенда из фронтенда: адрес API, CORS или прокси dev-сервера.
5. Проверить локальный запуск обоих проектов и сквозной вызов.
6. Удалить `.keepfolder` из `src/backend/` и `src/frontend/`.
7. Описать локальный запуск в документации.

**Выполнено:**

1. Создан бекенд-проект `src/backend/SociumApp/WebApi/` (ASP.NET Core Web API, .NET 10) и solution `src/backend/SociumApp/Solution-Socium.slnx`; `.keepfolder` из `src/backend/` удалён.
2. Добавлен тестовый эндпоинт `GET /api/room` — `RoomController.List` с атрибутной маршрутизацией; проверен локально, ответ HTTP 200.
3. Удалены лишние элементы шаблона: `UseAuthorization` и комментарии в `Program.cs`, дублирующий `appsettings.Development.json`; `WebApi.http` переведён на `https://localhost:7026/api/room`.
4. Создан фронтенд-проект `src/frontend/SociumWeb/` (Angular 22.2, standalone, zoneless, без SSR, CSS, префикс `app`); `.keepfolder` из `src/frontend/` удалён.
5. Настроен прокси dev-сервера `src/frontend/SociumWeb/proxy.conf.json`: запросы `/api` уходят на `https://localhost:7026`; подключён в `angular.json` (`serve.options.proxyConfig`). Проверено: `GET http://localhost:4200/api/room` возвращает HTTP 200 от бекенда.
6. Добавлены скрипты локального запуска `scripts/local/start-solution.ps1` (WebApi через `dotnet watch` и Angular на `127.0.0.1:4200` в отдельных окнах, пропуск уже запущенной части) и остановки `scripts/local/stop-solution.ps1` (по портам 7026 и 4200, вместе с цепочкой `dotnet watch`); `.keepfolder` из `scripts/` удалён.
7. Фронтенд очищен от демо-содержимого шаблона Angular: в `app.html` оставлен только `<router-outlet />`, из `app.ts` удалён неиспользуемый `title`, `styles.css` очищен, из `app.spec.ts` удалён тест демо-заголовка; сборка и тесты проходят.
