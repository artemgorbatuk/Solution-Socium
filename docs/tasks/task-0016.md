**Описание:**

Индикатор «печатает…» в открытом чате: участники видят, что кто-то набирает текст. Детали — при старте задачи.

**Функциональные требования:**

1. Typing: при наборе в composer остальные в открытом чате видят «печатает…» — уточняется при старте (таймаут, несколько печатающих).

**Технические требования:**

1. Нет. — уточняется при старте (SignalR / `Realtime` из [task-0014](task-0014.md)).

**План реализации:**

1. Карточка и реестр.
2. Уточнить требования и наполнить карточку.
3. Реализация, тесты, документы.
4. Коммит.
