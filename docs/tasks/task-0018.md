**Описание:**

В ленте сообщений между сообщениями разных календарных дней — разделитель с подписью даты («Сегодня», «Вчера» или дата). Сейчас дата видна только у времени пузырька (`message-time`); при длинной истории сложно ориентироваться по дням.

**Функциональные требования:**

1. Разделитель: перед первым сообщением каждого календарного дня в видимой ленте — линия с подписью — [Подписи](#подписи), [Разметка](#разметка).
2. Подписи: сегодня / вчера / иначе дата по-русски — [Подписи](#подписи).
3. История вверх: при `load older` разделители пересчитываются; не дублировать день — [Поведение](#поведение).
4. Realtime: новое сообщение другого дня (редко, смена суток) — появляется новый разделитель; того же дня — нет — [Поведение](#поведение).

**Технические требования:**

1. Только фронтенд (`chat-messages` + хелпер даты/разметки ленты); без API и миграций — `CreatedAt` уже UTC ISO, день считаем в локальной TZ браузера — как `message-time` ([As-is](#as-is)).
2. Локаль подписей: `ru-RU` (как `message-time.ts`) — [Подписи](#подписи).
3. Рендер: список элементов «разделитель | сообщение»; разделитель не в модели API — [Разметка](#разметка).
4. Стили: обе темы через `--sc-*`; компактная линия + центр-подпись — [UI](#ui).
5. Тесты FE: подписи Сегодня/Вчера/дата; появление разделителя между днями; load older / один день без лишних линий.
6. Документы: при необходимости коротко в карточке; rule — не обязателен.

**План реализации:**

1. Наполнить карточку; статус «В работе».
2. Хелпер: ключ дня, подпись, построение списка строк ленты.
3. Шаблон `chat-messages` + CSS разделителя.
4. Тесты; карточка «Выполнена»; коммит.

**Дополнительные сведения:**

### Решения разработчика

| Вопрос | Решение |
|--------|---------|
| Backend | Без изменений |
| Часовой пояс дня | Локальный браузера (как время у пузырька) |
| Локаль | `ru-RU` |
| Сегодня | Календарный день = сегодня |
| Вчера | Календарный день = вчера |
| Старше | `d MMMM yyyy` или `d MMMM` в том же году — на реализации, главное читаемо по-русски |
| Где рендер | Перед первым сообщением дня |
| Первый день в ленте | Разделитель тоже показываем (не только «между») |
| Sticky при скролле | Нет в этой задаче (обычный блок в потоке) |

### As-is

- `MessageListModel.createdAt` — UTC ISO.
- `message-time.ts`: `Intl` `ru-RU`; «сегодня» → только время; иначе дата+время у пузырька.
- Лента — `@for` по `messages()` без группировки по дням.

### Подписи

| День относительно «сейчас» | Текст |
|----------------------------|--------|
| Сегодня | `Сегодня` |
| Вчера | `Вчера` |
| Иначе | дата по `ru-RU` (например `9 октября 2026` / `9 октября`, если год текущий) |

Сравнение дней — по локальным Y-M-D от `createdAt`, не по UTC-полуночи (иначе «прыжок» у границы суток для пользователя).

### Разметка

Лента строится как последовательность элементов:

1. опционально `day-separator` с `label`;
2. `message` (существующий `app-message-item`).

Разделитель — `role="separator"` или заголовок с `aria-label` / видимым текстом даты.

### Поведение

1. Исходный `GET` последних 50 — разделители для всех дней в странице.
2. `beforeId` (история вверх) — prepend сообщений, пересчёт списка; скролл-якорь как сейчас ([task-0014](task-0014.md) / текущий `loadOlder`).
3. `messageCreated` / update текста — день от `createdAt` не меняется при update; delete — разделитель дня остаётся, пока в ленте есть хотя бы одно сообщение этого дня.
4. Смена чата — пересборка с нуля.

### UI

- Горизонтальная линия на всю ширину колонки ленты (max-width как у списка), по центру — подпись на фоне ленты/surface, чтобы «перерезать» линию.
- Цвет текста muted; линия — `border`.
- Без sticky; не карточка.

### Вне объёма

Sticky-дата при скролле; группировка по отправителю; изменение формата времени у пузырька; серверная локаль/TZ пользователя.
