**Описание:**

Создание, переименование и удаление сейчас спрятаны в меню «…» — это два клика и поиск пункта. Заменить меню на кнопки-иконки, которые появляются справа при наведении на строку, как в Cursor: у комнат, чатов и сообщений. Подтверждение удаления — тоже на месте строки, как переименование, а не модальным окном. Задача выполняется до [task-0010](task-0010.md).

**Функциональные требования:**

1. Комната: при наведении справа от названия — «Новый чат» (плюс), «Переименовать» (карандаш), «Удалить» (корзина); действия те же, что сейчас в меню — состав в [Кнопки по строкам](#кнопки-по-строкам).
2. Чат: при наведении — «Переименовать» (карандаш), «Удалить» (корзина) — состав в [Кнопки по строкам](#кнопки-по-строкам).
3. Сообщение: при наведении — «Изменить» (карандаш), «Удалить» (корзина) плавающей панелью сбоку справа от пузыря, вровень с его верхом; в узком окне, где справа от колонки нет места, панель переходит в правый верхний угол пузыря; пузырь не сдвигается и остаётся вровень с полем ввода — состав в [Кнопки по строкам](#кнопки-по-строкам).
4. Удаление: корзина (красная при наведении) заменяет строку формой подтверждения — как форма переименования, но вместо поля вопрос и кнопки «Удалить», «Отмена»; у сообщения пузырь остаётся, подтверждение — под ним; модальные окна удаления убираются — тексты в [Подтверждение удаления](#подтверждение-удаления).
5. Видимость: кнопки видны при наведении на строку, при фокусе клавиатуры внутри строки, у открытого чата и всегда на сенсорных экранах; пока строка в режиме переименования, изменения или подтверждения удаления, кнопок нет.
6. Подсказки: у каждой кнопки всплывающая подсказка с названием действия.
7. Меню «…»: убирается у комнат, чатов и сообщений.

**Технические требования:**

1. Иконки: общий компонент `app/shared/icon/` со встроенными SVG (`plus`, `pencil`, `trash`), цвет — `currentColor`, без новых npm-зависимостей; символы Юникода и эмодзи не используются — отрисовываются по-разному в разных системах.
2. Кнопка-иконка: общий вариант кнопки `icon` в `base.css` внутри `:where()` (квадратная, без рамки, фон при наведении `--sc-color-hover`); `icon danger` — красная при наведении; вариант добавляется в [rule-0005](../rules/rule-0005-frontend.md), пункт 6.
3. Видимость в CSS: `:hover` и `:focus-within` строки, класс открытого чата, `@media (hover: none)`; скрытие — через `opacity`, чтобы кнопки оставались доступными для Tab.
4. Доступность: у каждой кнопки `aria-label` с названием объекта — состав в [Кнопки по строкам](#кнопки-по-строкам); логика меню (открытие, закрытие по Escape, `aria-haspopup`) удаляется вместе с меню.
5. Стили: только токены `--sc-*` по [rule-0005](../rules/rule-0005-frontend.md); длинное название при появлении кнопок обрезается многоточием.
6. Тесты: по [rule-0004](../rules/rule-0004-tests.md) — спеки `room-list-item`, `chat-list-item`, `message-item` и компонента иконки; E2E, которые сейчас открывают меню «…», переходят на кнопки.
7. Подтверждение удаления: окна `RoomDeleteDialog`, `ChatDeleteDialog`, `MessageDeleteDialog` становятся компонентами `RoomDeleteConfirm`, `ChatDeleteConfirm`, `MessageDeleteConfirm`, которые строка показывает вместо себя; событие строки `deleteRequested` заменяется на `deleted`. Данные — из `GET api/{entity}/delete` по [rule-0003](../rules/rule-0003-backend.md): до ответа «Удалить» недоступна, вопрос с названием из списка виден сразу; фокус на «Отмена» (Enter не удаляет), Esc — отмена; `role="group"` с `aria-label` «Удалить комнату?», «Удалить чат?», «Удалить сообщение?».

**Дополнительные сведения:**

### Кнопки по строкам

| Строка    | Кнопки (слева направо)                  | `aria-label`                                                                                       |
|-----------|-----------------------------------------|----------------------------------------------------------------------------------------------------|
| Комната   | плюс, карандаш, корзина                 | «Новый чат в комнате {название}», «Переименовать комнату {название}», «Удалить комнату {название}» |
| Чат       | карандаш, корзина                       | «Переименовать чат {название}», «Удалить чат {название}»                                           |
| Сообщение | карандаш, корзина (сбоку справа)        | «Изменить сообщение», «Удалить сообщение»                                                          |

Подсказка (`title`) — короткое название действия: «Новый чат», «Переименовать», «Изменить», «Удалить».

### Подтверждение удаления

| Строка    | Где                          | Текст                                                                            |
|-----------|------------------------------|----------------------------------------------------------------------------------|
| Комната   | вместо строки комнаты        | «Удалить комнату «{название}»?», при чатах — «Вместе с комнатой будут удалены чаты: {N}» |
| Чат       | вместо строки чата           | «Удалить чат «{название}»?»                                                      |
| Сообщение | под пузырём, по правому краю | «Удалить сообщение?»                                                             |

Кнопки — «Отмена» слева и «Удалить» (`danger`) справа от неё, как «Отмена» и «Сохранить» в формах переименования.

### Решения разработчика

| Вопрос            | Решение                                                                                          |
|-------------------|--------------------------------------------------------------------------------------------------|
| Значок удаления   | Корзина, а не крест: крест в интерфейсе уже означает «Закрыть чат» и обычно значит «убрать из вида» |
| Где менять        | Везде — комнаты, чаты и сообщения, для единообразия                                               |
| Кнопки сообщения  | Плавающая панель сбоку справа от пузыря, за краем колонки ленты; в узком окне (лента уже 880 px) — в правом верхнем углу пузыря. Панель не в потоке: пузырь не сдвигается влево и совпадает с краем поля ввода |
| Подтверждение удаления | На месте строки, как переименование и создание, а не модальным окном; у сообщения — под пузырём. Оформлено в этой же карточке |
| Порядок кнопок форм | «Отмена» слева, основное действие («Создать», «Сохранить», «Удалить») — справа от неё; во всех формах и подтверждениях, закреплено в пункте 6 [rule-0005](../rules/rule-0005-frontend.md) |
