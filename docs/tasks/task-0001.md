**Описание:**

Подготовить репозиторий к работе: создать минимальную структуру папок и зафиксировать правила оформления задач и правил, чтобы дальнейшая работа велась по единому формату.

**Функциональные требования:**

1. Структура папок: минимальный каркас репозитория — есть отдельные места для кода, документации, скриптов, развёртывания и сертификатов; состав — в [Дополнительные сведения](#дополнительные-сведения).
2. Правило оформления задач: описано, как создавать и вести задачи — `docs/rules/rule-0001-tasks.md`.
3. Правило оформления правил: описано, как создавать и вести правила — `docs/rules/rule-0002-rules.md`.
4. Реестры: есть оглавления задач и правил — `docs/tasks.md`, `docs/rules.md`.

**Технические требования:**

1. Пустые папки: фиксируются в git файлом `.keepfolder` — файл удаляется, когда в папке появляется содержимое.
2. Формат документации: Markdown, язык — русский.
3. Нумерация: задачи и правила нумеруются сквозным 4-значным номером — `task-NNNN.md`, `rule-NNNN-<тема>.md`.
4. Шаблоны: новые задачи и правила создаются из шаблонов — `docs/tasks/.template.md`, `docs/rules/.template.md`.
5. Навигация: каждый файл задачи и правила содержит ссылку возврата в свой реестр — `docs/tasks.md`, `docs/rules.md`.

**План реализации:**

1. Создать структуру папок с файлами `.keepfolder`.
2. Описать правило оформления задач на основе шаблона задачи.
3. Описать правило оформления правил и шаблон правила.
4. Заполнить реестры задач и правил.
5. Оформить настоящую задачу по правилу rule-0001.

**Выполнено:**

1. Создана структура папок: `certs/`, `deploy/`, `docs/rules/`, `docs/runbook/`, `docs/tasks/`, `scripts/`, `src/backend/`, `src/frontend/` — пустые папки зафиксированы файлами `.keepfolder`; в `docs/rules/` и `docs/tasks/` они удалены, так как папки заполнены.
2. Создан шаблон задачи `docs/tasks/.template.md`.
3. Создано правило оформления задач `docs/rules/rule-0001-tasks.md`.
4. Создано правило оформления правил `docs/rules/rule-0002-rules.md` и шаблон правила `docs/rules/.template.md`.
5. Заполнены реестры задач `docs/tasks.md` и правил `docs/rules.md`.
6. Оформлена задача `docs/tasks/task-0001.md`.
7. Добавлено требование о ссылке возврата в реестр: в правила `docs/rules/rule-0001-tasks.md` и `docs/rules/rule-0002-rules.md`, в оба шаблона и во все существующие задачи и правила.
