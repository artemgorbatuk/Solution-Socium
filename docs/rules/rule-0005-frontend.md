# rule-0005: Frontend

[← Реестр правил](../rules.md)

**Назначение:**

Единые соглашения по стилям и темам фронтенда, чтобы оформление менялось в одном месте, а каждый экран одинаково работал в светлой и тёмной теме.

**Область применения:**

Стили и разметка фронтенда `src/frontend/SociumWeb/src/`: глобальные стили, `*.css` компонентов, `index.html`, сервис темы.

**Правила:**

1. Токены: цвета, тени, скругления, шрифты и шаг отступов задаются только CSS-переменными `--sc-*` из `src/styles/tokens.css`; литералы цветов (`#…`, `rgb()`, именованные цвета) в стилях компонентов не используются.
2. Именование токенов: общие — `--sc-{группа}-{роль}[-{состояние}]`, группы — `color`, `shadow`, `radius`, `space`, `font`; компонентные (цвета, которые есть только у одной сущности интерфейса) — `--sc-{сущность}-{роль}-{свойство}`, свойства — `bg`, `border`, `text` (`--sc-message-sender-bg`, `--sc-message-recipient-border`); роль описывает назначение, а не внешний вид (`--sc-color-text-muted`, `--sc-color-danger-hover`, но не `--sc-gray-500`).
3. Темы: значения светлой темы — на `:root`, тёмная тема — `:root[data-theme='dark']` и переопределяет только цветовые токены и тени; в каждой теме задан `color-scheme`, чтобы системные элементы (полосы прокрутки, автозаполнение) совпадали с темой.
4. Новый токен: добавляется сразу в обе темы, если он цветовой; компонентные токены тоже задаются в `tokens.css` отдельным блоком после общих цветов; компонент не вводит собственных цветовых переменных в обход `tokens.css`.
5. Структура: `src/styles.css` только импортирует `styles/tokens.css` (переменные) и `styles/base.css` (сброс, базовые элементы); стили компонента — в его `{компонент}.css` рядом с компонентом.
6. Базовые элементы: базовые стили `button`, `input` и состояния фокуса пишутся в `base.css` внутри `:where()` (нулевая специфичность), чтобы стили компонента переопределяли их без `!important`; варианты кнопок — классы `primary` (основное действие), `danger` (необратимое действие) и `icon` (кнопка-иконка компонента `app-icon` с `aria-label` и `title`; `icon danger` — необратимое действие, красное только при наведении); в формах и подтверждениях «Отмена» стоит слева, основное действие («Создать», «Сохранить», «Удалить») — справа от неё.
7. `!important`: не используется.
8. Размеры: отступы — по шкале `--sc-space-1` … `--sc-space-5` (4–20 px с шагом 4); разовые размеры конкретного элемента (ширина панели, размер иконки) допускаются числами.
9. Тема в коде: текущая тема — сервис `Theme` (`app/shared/theme/theme.ts`); тема применяется атрибутом `data-theme` на `<html>`, выбор хранится в `localStorage` под ключом `socium.theme`. Встроенный скрипт в `index.html` применяет сохранённую тему до загрузки Angular; ключ и значения в нём совпадают с сервисом.
10. Ключи `localStorage`: с префиксом `socium.` и точкой между частями (`socium.theme`, `socium.sidebar.width`).
11. Доступность: контраст основного текста к фону — не ниже 4.5:1 в обеих темах; фокус клавиатуры виден (`:focus-visible` с токеном `--sc-color-focus`); у кнопок-иконок есть `aria-label`, называющий действие.
12. Проверка: изменение стилей проверяется в браузере в обеих темах.

**Исключения:**

Нет.
